# Support

For reproducible bugs and feature requests, please use the public GitHub issue
tracker: <https://github.com/nimh-sfim/egi-pynetstation/issues>.

For questions about experimental timing or configuring a supported EGI system,
first consult the documentation and examples. When opening an issue, include a
minimal example, package version, Python version, operating system, and the
result of `python -m egi_pynetstation.check_clocks`. Do not include participant
data, recordings, credentials, or institutional network details.

For a security-sensitive issue that should not be public, contact
`Peter.Molfese@nih.gov`.
