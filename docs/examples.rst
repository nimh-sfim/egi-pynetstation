Examples
========

The example scripts live in the repository root.

Start here
----------

``example3_stroop.py``
   A complete PsychoPy task with stimulus and response markers.

``example4_psychopydemo.py``
   The smallest PsychoPy integration.

``example.py``
   A non-visual ECI example; no PsychoPy required.

Diagnostics
-----------

``example2.py``
   An interactive ECI console for testing a connection and responses.

``check_clocks.py``
   Reports the clock paths and their measured resolution. See
   :doc:`timing_test`.

``example5_psychopy_photocell_drift.py``
   The required photocell timing test for a stimulus setup. See
   :doc:`timing_test` for the command and how to interpret it.

``example5_psychopy_photocell_drift_gui.py``
   A PsychoPy dialog for the same timing test.
